## 2024-05-24 - Dynamic state feedback in HUD
**Learning:** Keyboard shortcut lists in a HUD can become confusing if they show the name of an action (e.g. "pause") when the game is already in that state. Context-aware hints are a great micro-UX addition.
**Action:** Always check if a toggle keyboard shortcut hint can be made state-aware (e.g., swapping "pause" for "resume" dynamically). Additionally, ensure all keyboard shortcut hints are descriptive (e.g. `[+/-] speed` instead of just `[+/-]`).
